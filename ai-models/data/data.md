# Nguồn dữ liệu

- Tên: Breast Cancer Wisconsin (Diagnostic) Data Set
- Nguồn: Kaggle (uciml/breast-cancer-wisconsin-data), gốc UCI Machine Learning Repository
- Giấy phép: (chép đúng giấy phép ghi trên trang Kaggle của dataset)
- Quy mô: 569 mẫu, 30 đặc trưng số, cột mục tiêu diagnosis (M = ác tính, B = lành tính)
- Cách giải nén: unzip dataset.zip (hoặc giải nén bằng chuột phải)
